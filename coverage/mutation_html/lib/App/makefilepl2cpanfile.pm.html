  359: =head2 parse_prereqs($content)

  383: C<CONFIGURE_REQUIRES> hashes, mapped to the C<requires> relationship of the
  384: C<runtime>, C<build>, C<test> and C<configure> phases respectively.

  386: =item * Structured C<prereqs =E<gt> { phase =E<gt> { rel =E<gt> { ... } } }>
