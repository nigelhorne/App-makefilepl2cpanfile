  392: =head2 parse_prereqs($content)
  393: 
  394: =head3 PURPOSE
  395: 
  396: Extracts all dependency declarations from the text of a C<Makefile.PL> and
  397: returns them structured by cpanfile phase and relationship.  Exposed as a
  398: public function so callers (e.g. C<bin/makefilepl2cpanfile --check>) can
  399: reuse the parsing logic without duplicating it.  The text is never
  400: evaluated.
  401: 
  402: =head3 ARGUMENTS
  403: 
  404: =over 4
  405: 
  406: =item * C<$content> (Str) - the raw text of a C<Makefile.PL>.  An undefined
  407: value or a reference is treated as containing no dependencies.
  408: 
  409: =back
  410: 
  411: The following forms are recognised:
  412: 
  413: =over 4
  414: 
  415: =item * C<PREREQ_PM>, C<BUILD_REQUIRES>, C<TEST_REQUIRES> and
  416: C<CONFIGURE_REQUIRES> hashes, mapped to the C<requires> relationship of the
  417: C<runtime>, C<build>, C<test> and C<configure> phases respectively.
  418: 
  419: =item * Structured C<prereqs =E<gt> { phase =E<gt> { rel =E<gt> { ... } } }>
  420: blocks (CPAN Meta Spec 2), wherever they appear, including under
  421: C<META_MERGE>.  Only the phases and relationships listed in
  422: L</DATA STRUCTURE> are used; any others are ignored.
  423: 
  424: =item * Legacy (META spec 1.x style) top-level C<recommends =E<gt> { ... }>
  425: and C<suggests =E<gt> { ... }> hashes, typically under C<META_MERGE>,
  426: mapped to the C<runtime> phase.  Such hashes inside a C<prereqs> block
  427: belong to that block's phase only.
  428: 
  429: =back
  430: 
  431: Only entries whose key is a quoted, valid Perl package name are used.
  432: Commented-out code is skipped, including a whole dependency hash written on
  433: one line after a C<#>.  A version is an optional C<v> followed by ASCII
  434: digits, dots and underscores containing at least one digit; anything else
  435: (for example C<'.'>) is treated as no minimum version.  When a module appears more than once in
  436: the same phase and relationship, the first occurrence wins, and the simple
  437: keys are read before C<prereqs> blocks.
  438: 
  439: =head3 RETURNS
  440: 
  441: A HashRef as described in L</DATA STRUCTURE>.  Phases and relationships
  442: with no entries are absent.  C<version> is C<0> when no minimum is
  443: declared; C<comment> holds the text of an inline C<#> comment on the entry,
  444: or C<undef> when there is none.
  445: 
  446: =head3 SIDE EFFECTS
  447: 
  448: None.  No I/O, no warnings, and the caller's C<$@>, C<$!> and C<$_> are
  449: left unchanged.
