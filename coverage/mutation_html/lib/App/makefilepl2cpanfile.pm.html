  365: =head2 parse_prereqs($content)
  366: 
  367: =head3 PURPOSE
  368: 
  369: Extracts all dependency declarations from the text of a C<Makefile.PL> and
  370: returns them structured by cpanfile phase and relationship.  Exposed as a
  371: public function so callers (e.g. C<bin/makefilepl2cpanfile --check>) can
  372: reuse the parsing logic without duplicating it.  The text is never
  373: evaluated.
  374: 
  375: =head3 ARGUMENTS
  376: 
  377: =over 4
  378: 
  379: =item * C<$content> (Str) - the raw text of a C<Makefile.PL>.  An undefined
  380: value or a reference is treated as containing no dependencies.
  381: 
  382: =back
  383: 
  384: The following forms are recognised:
  385: 
  386: =over 4
  387: 
  388: =item * C<PREREQ_PM>, C<BUILD_REQUIRES>, C<TEST_REQUIRES> and
  389: C<CONFIGURE_REQUIRES> hashes, mapped to the C<requires> relationship of the
  390: C<runtime>, C<build>, C<test> and C<configure> phases respectively.
  391: 
  392: =item * Structured C<prereqs =E<gt> { phase =E<gt> { rel =E<gt> { ... } } }>
  393: blocks (CPAN Meta Spec 2), wherever they appear, including under
  394: C<META_MERGE>.  Only the phases and relationships listed in
  395: L</DATA STRUCTURE> are used; any others are ignored.
  396: 
  397: =item * Legacy (META spec 1.x style) top-level C<recommends =E<gt> { ... }>
  398: and C<suggests =E<gt> { ... }> hashes, typically under C<META_MERGE>,
  399: mapped to the C<runtime> phase.  Such hashes inside a C<prereqs> block
  400: belong to that block's phase only.
  401: 
  402: =back
  403: 
  404: Only entries whose key is a quoted, valid Perl package name are used;
  405: commented-out lines are skipped.  When a module appears more than once in
  406: the same phase and relationship, the first occurrence wins, and the simple
  407: keys are read before C<prereqs> blocks.
  408: 
  409: =head3 RETURNS
  410: 
  411: A HashRef as described in L</DATA STRUCTURE>.  Phases and relationships
  412: with no entries are absent.  C<version> is C<0> when no minimum is
  413: declared; C<comment> holds the text of an inline C<#> comment on the entry,
  414: or C<undef> when there is none.
